# Сервис защищённого соединения в 1 клик

Нажал Deploy → подождал → скопировал ссылку из логов → вставил в клиентское приложение. Всё с телефона, без консоли и настроек.

## Деплой (только кнопки, ~5 минут)

1. Зайди на сайт хостинга с телефона через браузер.
2. New Project → Deploy from GitHub → выбери `KamiSakyy/Lsmsnksoslalql`.
3. Выбери ветку `arena/07184cc8-lsmsnksoslalql`: сервис → Settings → Source → Branch → подождать сборку.
4. Выдай домен: Settings → Networking → Generate Domain.
5. Подожди 1–2 минуты (статус Active).
6. Открой свой домен в браузере — увидишь страницу «Сервис запущен». В этот момент сервер узнает домен сам.
7. Открой Deploy Logs → найди «🎉 ДОМЕН УЗНАН САМ» и ниже ссылку → скопируй целиком.
8. Вставь ссылку в клиентское приложение (какое именно — подскажет ассистент в чате) → подключись → проверь на 2ip.ru, что страна сменилась.

Ссылка не меняется при перезапусках. Сменишь домен — открой новый домен в браузере и скопируй новую ссылку из свежих логов.

## Если хостинг заблокировал деплой

Некоторые бесплатные хостинги запрещают такие сервисы. Попробуй другой: Railway, Render, Koyeb или Fly.io — шаги везде одинаковые.

## Чиним проблемы кнопками

| Симптом | Что сделать |
|---|---|
| В логах «⏳ Домена пока нет» | Открой свой домен в браузере → подожди 10 сек → обнови логи |
| Клиент пишет ошибку сети | Подожди минуту, переподключись; проверь, что ссылка скопирована целиком |
| Долго не соединяется | Убери из ссылки кусок `&alpn=h2` и вставь заново |
| Статус Crash/Failed | Нажми Redeploy |

## Безопасность

- Ссылка = ключ от твоего сервиса. Никому её не давай.
