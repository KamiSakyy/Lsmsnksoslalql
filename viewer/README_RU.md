# Просмотр результата в 3D

Лёгкий интерактивный просмотрщик результата из `handoff/rigged/anime-girl-rigged.glb`.
Никаких CDN, внешнего API или передачи модели стороннему сервису: Three.js и модель
выдаются тем же локальным сервером, запросы браузера используют относительные URL.

Из корня репозитория:

```sh
npm ci --prefix viewer
npm start --prefix viewer
```

Сервер слушает `0.0.0.0:3000`; порт можно изменить переменной `PORT`.

- Пять кнопок включают отдельные клипы.
- Пауза, шкала времени и скорость управляют воспроизведением.
- Переключатель «Показать кости» включает реальный `SkeletonHelper` модели.
- «Исходная поза» останавливает анимации и возвращает bind pose.
- Мышь/касание вращают камеру, колесо меняет масштаб; кнопка ⌖ сбрасывает ракурс.
- «Скачать GLB» сохраняет фактический результат, не картинку и не исходник без костей.

Сервер выдаёт только файлы просмотрщика, установленный Three.js, готовый GLB и отчёт.
Исходный ZIP, сервер приложения и файлы с учётными данными не публикуются.

Если `handoff/rigged` ещё не создан, сначала дождитесь успешного завершения
`.github/workflows/rig-model.yml` и получите изменения этой рабочей ветки.
