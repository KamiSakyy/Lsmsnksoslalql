# 📖 Обучение «Милы» на своём голосе — пошагово

Здесь всё, что нужно, чтобы получить модель, которая говорит **твоим голосом**.
Итоговый файл `mila.onnx` весит **до 100 МБ** и работает офлайн.

---

## Шаг 0. Что понадобится

| | |
|---|---|
| **Аудио** | 10–50 минут чистой речи (mp3/wav). Чем больше и чище, тем лучше |
| **Текст** | Транскрипт каждой записи (можно автоматически, см. Шаг 2) |
| **GPU** | Желателен (Google Colab бесплатно). На CPU тоже работает, но медленнее |
| **Python** | 3.10–3.12 |

> 💡 Советы по записи: говори спокойно и ровно, одной манерой; без музыки и
> шумов; фразы средней длины (3–12 секунд); можно записать на телефон.

---

## Шаг 1. Положи mp3 в репозиторий

```
data/voice_samples/
├── 001.mp3
├── 002.mp3
├── 003.mp3
└── ...
```

Именно так — mp3 коммитятся в репозиторий (или просто лежат локально,
обучение одинаково работает и там и там).

---

## Шаг 2. Транскрипты (текст записей)

Формат `metadata.csv` — по строке на файл:

```
001.mp3|Привет, меня зовут Аня, и это запись моего голоса.
002.mp3|Сегодня я расскажу тебе интересную историю.
```

Варианты:
* **написать самому** — самый точный;
* **текстовые файлы** рядом: `001.txt` с текстом (обработчик сам подхватит);
* **автоматически** — faster-whisper расшифрует речь (нужен интернет один раз
  для загрузки модели):

```bash
pip install faster-whisper
python -m training.preprocess --input data/voice_samples --out data/processed --auto-transcribe
```

---

## Шаг 3. Подготовка датасета

```bash
pip install -r requirements-train.txt
python -m training.preprocess --input data/voice_samples --out data/processed \
    --metadata data/voice_samples/metadata.csv
```

Что делает препроцессинг:
* декодирует mp3 (soundfile / ffmpeg);
* убирает тишину по краям, режет длинные записи по паузам (≤12 с);
* приводит к 22050 Гц моно и выравнивает громкость (RMS −20 dB);
* пишет готовый `data/processed/metadata.csv`.

## Шаг 4. Обучение

### Вариант А — Google Colab (бесплатный GPU, ~1–3 часа)

Начни ноутбук с GPU («Среда выполнения → Сменить среду → GPU») и выполняй
построчно:

```python
# 1. клонируем репозиторий (после того как запушил mp3)
!git clone https://github.com/<твой-аккаунт>/<репозиторий>.git
%cd <репозиторий>/cute-tts

# 2. зависимости
!pip install -r requirements-train.txt

# 3. подготовка данных (если не делал локально)
!python -m training.preprocess --input data/voice_samples --out data/processed \
    --metadata data/voice_samples/metadata.csv

# 4. обучение (3000 шагов, batch 8 — хватит на старт)
!python -m training.train --config configs/mila.yaml --out models/run_voice --steps 3000

# 5. экспорт в ONNX (с проверкой лимита 100 МБ)
!python -m training.export --checkpoint models/run_voice/latest.pt --out models/mila.onnx

# 6. проверка
!python -m cute_tts "Привет! Это мой новый голос." -m models/mila.onnx -o check.wav

# 7. скачать модель
from google.colab import files
files.download('models/mila.onnx')
files.download('models/mila.onnx.json')
```

Положи скачанные `mila.onnx` + `mila.onnx.json` в `models/` репозитория и
закоммить — GitHub Actions соберёт готовое приложение.

### Вариант Б — локально на GPU

```bash
python -m training.train --config configs/mila.yaml --out models/run_voice
python -m training.export --checkpoint models/run_voice/latest.pt --out models/mila.onnx
```

Ориентиры по времени: RTX 3060 — ~30–40 минут на 3000 шагов; CPU — часы
(лучше Colab).

### Вариант В — прямо в GitHub Actions

**Actions → MilaTTS Train → Run workflow → mode: `voice`**
(в репозитории должны лежать `data/voice_samples/` с mp3 и `metadata.csv`).
Runner'ы GitHub — CPU, поэтому ставь `steps` разумным (обычно нужно больше,
но для проверки сойдёт); готовая модель придёт артефактом `mila-voice`.

## Шаг 5. Проверка и тонкая настройка

```bash
python -m cute_tts "Как тебе мой голос?" -o out.wav
python -m cute_tts "Медленно и выразительно" --speed 0.85 --expressiveness 0.8 -o out.wav
python -m cute_tts --web   # красивый локальный интерфейс
```

| Параметр | Где | Эффект |
|---|---|---|
| `--speed` | CLI | 0.5 — медленно, 2.0 — быстро |
| `--expressiveness` | CLI | 0 — ровно, 1 — живо и вариативно |
| `train.steps` | `configs/mila.yaml` | больше шагов → чище звук (до ~6000) |
| `model.hidden` | `configs/mila.yaml` | 192 (≈60 МБ) ↔ 160 (≈45 МБ) ↔ 128 (≈25 МБ) |

Если модель не влезла в 100 МБ — `training/export.py` автоматически сделает
int8-версию и проверит лимит ещё раз.

## Шаг 6. Сборка приложения (GitHub Actions)

1. Закоммить `models/mila.onnx` + `models/mila.onnx.json`.
2. **Actions → MilaTTS Build** запустится сам (или вручную).
3. После сборки забери бинарники из артефактов `mila-tts-<os>`
   (Linux / Windows / macOS, работает без Python и без интернета).
4. Хочешь релиз — создай тег:

```bash
git tag mila-v1.0 && git push origin mila-v1.0
```

и GitHub Release прикрепит все сборки автоматически.

## Частые вопросы

**Сколько данных нужно для хорошего качества?**
10 минут — голос узнаваем, но синтетично; 30–50 минут чистой речи — уже очень
прилично; 1+ час — почти студийное сходство.

**Модель выдаёт кашу на длинных фразах?**
Разбей текст на предложения — приложение само озвучивает по фразам;
увеличь `steps` и проверь транскрипты (ошибки в тексте = ошибки в речи).

**Можно переобучить на другом голосе?**
Да — новый `data/voice_samples/` и тот же конвейер; получишь второй `.onnx`,
их можно держать в `models/` несколько штук.

**Как обновить готовый голос «Ирина» до своего?**
Просто замени `mila.onnx` — или удали `irina.onnx`, чтобы не путать.
