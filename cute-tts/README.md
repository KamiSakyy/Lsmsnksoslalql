# 🎀 Мила — оффлайн-конвертер текста в голос

**MilaTTS** — приложение, которое превращает текст в реалистичную речь милого
девичьего голоса. Работает **полностью офлайн** (без интернета), модель весит
**до 100 МБ**, умеет **обучаться на твоём голосе** по mp3-записям и собирается
в переносные бинарники через **GitHub Actions**.

```
текст  →  нормализация  →  фонемы  →  нейросеть VITS (≤100 МБ)  →  голос.wav
              всё локально, без облаков и без интернета
```

---

## Как это работает

### 1. Конвейер синтеза (инференс)

| Шаг | Что происходит | Где |
|---|---|---|
| **Нормализация** | Числа, даты, время, проценты, телефоны превращаются в слова: «12.05.2024» → «двенадцатое мая две тысячи двадцать четвёртого года» | `cute_tts/normalize.py` |
| **Фонемизация** | Текст разбивается на фонемы через встроенный espeak-ng (звук «р», «а», «т»…). Работает офлайн | `cute_tts/phonemize.py` |
| **Нейросеть** | Компактная модель **VITS** (энкодер текста + предсказатель длительности + поток + HiFi-GAN декодер) синтезирует звук | `models/*.onnx` + `cute_tts/engine.py` |
| **Склейка** | Фразы озвучиваются по очереди и склеиваются с паузами, громкость выравнивается | `cute_tts/engine.py` |

Всё выполняется на CPU за секунды. Интернет не нужен ни на каком шаге —
ни для текста, ни для голоса.

### 2. Обучение на своём голосе

Ты загружаешь mp3 с записями своего голоса в `data/voice_samples/`, и конвейер
**дообучает модель говорить твоим голосом**:

```
твои mp3  →  чистка/тишина/громкость  →  транскрипты (metadata.csv)
          →  обучение VITS (GPU 1-3 часа)  →  export ONNX (≤100 МБ)
          →  models/mila.onnx — теперь это ТВОЙ голос
```

Подробная пошаговая инструкция: **[docs/ОБУЧЕНИЕ.md](docs/ОБУЧЕНИЕ.md)**.

### 3. Вес модели — до 100 МБ

| Вариант | Размер | Качество |
|---|---|---|
| `configs/mila.yaml` fp32 | ~55–75 МБ | максимальное |
| экспорт с `--int8` (автоматически при превышении) | ~15–20 МБ | почти без потерь |
| готовый голос Piper «Ирина» (скачивается один раз) | 67 МБ (или 21 МБ int8) | реалистичный женский ru |

Экспорт (`training/export.py`) **проверяет лимит** и сам переключается на
int8-квантизацию, если модель вдруг весит больше 100 МБ.

## Быстрый старт

```bash
cd cute-tts
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-app.txt

# озвучить текст (модель кладётся в models/)
python -m cute_tts "Привет! Я Мила, твой оффлайн голос." -o hello.wav

# свойства голоса
python -m cute_tts "Скорость и выразительность" --speed 0.85 --expressiveness 0.7 -o out.wav

# милый локальный веб-интерфейс (127.0.0.1, без интернета)
python -m cute_tts --web          # → http://127.0.0.1:8765
```

### Готовый голос сразу (по желанию)

Если интернет есть один раз — можно скачать реалистичный женский русский
голос Piper «Ирина» и пользоваться, пока обучается твой:

```bash
bash scripts/get_voice.sh          # fp32, ~67 МБ
python -m cute_tts "Привет!" -m models/irina.onnx -o hello.wav
```

### Проверить весь пайплайн за 3 минуты (без своего голоса)

```bash
pip install -r requirements-train.txt
python -m training.make_demo_dataset --out data/demo     # демо-данные (espeak)
python -m training.train --config configs/demo.yaml --out models/run --steps 300
python -m training.export --checkpoint models/run/latest.pt --out models/mila.onnx
python -m cute_tts "Тест пайплайна" -o test.wav
```

## Обучение на своём голосе (кратко)

1. **Запиши 10–50 минут речи** (можно несколькими mp3, чистый звук, без музыки).
2. Положи файлы в `data/voice_samples/`, а текст каждой записи — в
   `data/voice_samples/metadata.csv` (строки `имя.mp3|текст фразы`)
   или рядом `.txt`-файлы. Если текста нет — расшифровка автоматом
   (`--auto-transcribe`, faster-whisper).
3. Подготовка и обучение (GPU):

```bash
python -m training.preprocess --input data/voice_samples --out data/processed \
    --metadata data/voice_samples/metadata.csv
python -m training.train --config configs/mila.yaml --out models/run_voice
python -m training.export --checkpoint models/run_voice/latest.pt --out models/mila.onnx
```

4. Готово — `models/mila.onnx` говорит твоим голосом.

Нет GPU? Варианты: Google Colab (бесплатно, команда одна — см.
[docs/ОБУЧЕНИЕ.md](docs/ОБУЧЕНИЕ.md)), либо кнопка **Actions → MilaTTS Train**
в GitHub (медленнее, но всё само).

## Сборка через GitHub Actions

В репозитории настроены два workflow (лежат в `.github/workflows/`):

| Workflow | Запуск | Что делает |
|---|---|---|
| **`tts-build.yml`** | автоматически при изменении `cute-tts/**` | тесты → смоук-обучение → сборка переносных бинарников **Linux / Windows / macOS** (PyInstaller) → артефакты; по тегу `mila-v1.0` — GitHub Release |
| **`tts-train.yml`** | вручную (Actions → MilaTTS Train → Run workflow) | режим `smoke` — проверка пайплайна; режим `voice` — обучение на твоих mp3 прямо в CI → артефакт `mila-voice` с готовой моделью |

Собранная папка выглядит так:

```
mila-tts-linux/
├── mila-tts            # бинарник: ./mila-tts "Привет!" -o hi.wav
├── models/
│   ├── mila.onnx       # модель (≤100 МБ)
│   └── mila.onnx.json  # конфиг (язык, фонемы, настройки)
└── README.md
```

Бинарник работает без Python и без интернета — просто распакуй и запускай.

## Честные ожидания по качеству

* **Твой голос (обучение на 20–50 минутах речи)** — узнаваемая манера,
  тембр и интонации твоего голоса; сильный акцент/смех/шёпот воспроизводятся
  хуже, чем в записи. Чем больше и чище данных — тем лучше.
* **Готовый голос «Ирина»** — реалистичная женская русская речь «из коробки».
* **Демо-модель из смоук-теста** — нужна только для проверки пайплайна,
  звучит как синтезированная речь.
* Модель учится на одной фразе-с-транскриптом; эмоции регулируются флагом
  `--expressiveness` (шум в латентном пространстве).

## FAQ

**Почему всё офлайн?** Модель — один ONNX-файл на CPU, фонемизация — espeak-ng
из pip-пакета, никаких облачных API.

**Почему именно VITS?** Единая end-to-модель «текст→звук» даёт естественные
интонации и укладывается в 100 МБ при обучении на одном голосе.

**Можно несколько голосов?** Да — положи несколько `*.onnx` в `models/` и
выбирай через `--model` (или `MILA_MODEL=/путь/к/модели.onnx`).

**Модель не найдена?** Положи `mila.onnx` + `mila.onnx.json` в `models/`
рядом с приложением или укажи `--model`.
