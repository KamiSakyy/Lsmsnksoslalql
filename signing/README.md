# Подпись Android-релизов

Публичный сертификат `NoirP2P-release-cert.pem` используется CI для сверки подписи. Постоянный keystore находится в `handoff/NoirP2P-release-keystore.p12`, пароль — в `handoff/NoirP2P-release-keystore-password.txt`, alias — `noirp2p-release`. Workflow читает эти файлы из checkout и не требует GitHub Actions Secrets для подписи.

## Важное предупреждение о публичной копии ключа

Владелец проекта явно попросил хранить signing keystore и пароль в `handoff/`. Репозиторий публичный, поэтому оба файла видны всем, попадут в исходный ZIP и сохранятся в истории Git и форках. Любой человек сможет подписать поддельное приложение тем же ключом; Android может принять его как обновление настоящего Noir P2P. Удаление файлов позже не удалит уже скачанные копии или историю. Это существенно небезопаснее GitHub Actions Secrets.

APK содержит подпись и публичный сертификат, но **не приватный ключ**. Не заменяйте и не пересоздавайте этот keystore после первой установки release: Android не примет обновление с другой подписью. Храните отдельную резервную копию keystore и пароля.
