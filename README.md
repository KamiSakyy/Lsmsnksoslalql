# Lsmsnksoslalql

## 🎌 Аниме-бот AniLibria → Telegram (MTProto, файлы до 2 ГБ)

Полная документация — [BOT_README.md](BOT_README.md). Кратко:

* **Умный роутинг по api_id/api_hash**: если Telegram не пускает одну пару
  (`API_ID_PUBLISHED_FLOOD`, `FLOOD_WAIT`, мёртвая сессия) — бот берёт следующую,
  помнит результат в `/data` и не устраивает шторм попыток. Проверка: `python anime_bot.py --creds`.
  Публичные пары Telegram почти всегда ограничены — нужна своя с https://my.telegram.org
  (в `api_keys.py` → `PRIVATE_CREDENTIALS` или Railway → Variables `API_ID`/`API_HASH`).
* Поиск инлайном: карточка тайтла → тап → сразу выбор серии и качества.
* Скачивание HLS параллельно и адаптивно (безопасный старт 3 → 6 → 8), прогресс обновляется
  каждые ~2 с даже в паузах CDN («CDN тормозит — пауза N с»).
* Канал-хранилище + Firebase RTDB: серия качается один раз, уходит в канал `-1004445072922`,
  повторный запрос любому пользователю — мгновенная копия из канала (без имени канала).
* Деплой: Dockerfile в корне ветки, Railway → Root = `/`, Volume на `/data`.
