# Lsmsnksoslalql

## Полная модель девушки — теперь с мимикой и отдельными пальцами

**[Скачать GLB — 89,77 МБ](https://github.com/KamiSakyy/Lsmsnksoslalql/raw/refs/heads/arena/1e52fcec-lsmsnksoslalql/handoff/rigged/anime-girl-rigged.glb)**

Исходная детализация сохранена: **1 159 795 вершин, 1 981 742 треугольника,
текстуры 4096 × 4096**. Исходные координаты, нормали, UV, индексы и изображения
побайтно неизменны в нейтральной позе. Никакого упрощённого заменителя, сайта или эмулятора.
Файл сохранён непосредственно в Git-ветке `arena/1e52fcec-lsmsnksoslalql`.

### Добавлены реальные управления

- **100 skin joints**: исходный риг тела/волос/одежды + **30 костей пальцев** + **22 кости лица**.
- На обеих руках все пять пальцев имеют **три отдельные фаланги** со стандартными именами
  `mixamorig:LeftHandIndex1..3`, `mixamorig:RightHandThumb1..3` и т. п.
- `Face.*` управляют челюстью, веками, бровями, губами/углами рта, щёками и носом.
  Все эти кости реально взвешены на исходный меш; не просто записаны в списке.
- **40 настоящих facial morph targets**: раздельное моргание и прищур, глаза, брови,
  улыбка/нахмуривание, губы, челюсть, щёки и формы **A / I / U / E / O**.
  В самом GLB находятся локальные POSITION/NORMAL-дельты, а не изображения выражений.
- **12 клипов**: Idle, Walk_InPlace, Run_InPlace, Wave, Dance, Finger_Curl,
  Finger_Spread, Finger_Isolation, Blink, Smile, Visemes, Facial_Expressions.

### Более точная привязка

Подгонка пальцев сделана по **реальной согнутой исходной 3D-позе** и поверхности каждой кисти,
а не по прямому шаблону. Привязка использует локальные bounded biharmonic fields.
Дальние влияния пальцев на воротник/прядь ограничены плавной областью поддержки;
исходный захват волос левой рукой учтён в допустимом диапазоне демонстрационного сгибания.
Суставы остаются независимо редактируемыми.

Лицо выделено геодезикой от носа; глаза и линия губ измерены по геометрии и реальным UV/текстуре.
Кожа лица перепривязана к голове/лицевым управлениям вместо дальних влияний позвоночника/волос.
Веса — **16 бит**, до четырёх влияний, **0 непривязанных вершин**.

### Полноразмерные редактируемые файлы

**[Скачать пакет GLB / Blender / FBX](https://github.com/KamiSakyy/Lsmsnksoslalql/actions/runs/38552808834/artifacts/11887757794)**.
В .blend сохранены все 100 точных суставных матриц, реальные vertex groups,
40 shape keys и action-клипы. Риг реконструирован из записанных матриц итогового файла,
не по приблизительной эвристике длины маленьких костей импортёра.

В Blender: `AnimeGirl_Original_HighDetail` → Object Data → Shape Keys;
для костей: `AnimeGirl_Precision_Rig_100` → Pose Mode.
Пакет Actions хранится 90 дней; основной GLB в Git не ограничен этим сроком.

[Полные имена управлений и ограничения](handoff/rigged/README_RU.md),
[машинный отчёт](handoff/rigged/rig-report.json),
[Khronos](handoff/rigged/khronos-validation.json),
[подгонка суставов](handoff/rigged/joint-fitting.json).

Это модель-специфичный автоматический риг, не обещание ручной студийной точности любой позы.
Исходный рот — закрытая поверхность: губы/челюсть действительно деформируются, но скрытые
зубы, язык и ротовая полость не реконструируются. Глаза остаются исходной текстурированной
поверхностью. Соприкасающиеся/слитые участки пальцев и захват волос ограничены исходной
топологией; крайние контактные позы могут требовать ручной корректировки. Движения процедурные,
не motion capture. Исходный ZIP, сервер и его конфигурация не изменены.
