# Tsuyu High-Performance Messenger (2026 Core Engine)

## Railway & Cloud Deployment (Docker)
Этот репозиторий готов к мгновенному развёртыванию в 1 клик на **Railway**, **Render**, **Fly.io**, **VPS** или любом Docker-хостинге.

### Развёртывание на Railway:
1. Создайте новый проект на [Railway.app](https://railway.app).
2. Выберите **Deploy from GitHub repo** и выберите этот репозиторий.
3. Всё готово! Railway автоматически определит `Dockerfile` и `railway.json` в корне репозитория и запустит сервис.
4. Скопируйте предоставленный публичный домен (например, `xxx.up.railway.app`) и введите его в Android-приложении Tsuyu при входе!

### Преимущества новой архитектуры:
- **Никакого Firebase RTDB или внешних зависимостей**: всё хранится и обрабатывается автономно на сервере.
- **Никакого Base64 в сообщениях и файлах**: прямая быстрая передача через Streaming Multipart API.
- **Высокопроизводительный протокол TsuyuProto (MTProto 2026-like)** через асинхронные WebSocket-сокеты с мгновенной доставкой сообщений, статусов присутствия и индикаторов набора текста.
- **Поддержка динамического порта `$PORT`** (в соответствии со стандартами Railway/Docker).
