**[Скачать полный GLB со скелетом и анимациями — 84,39 МБ](https://github.com/KamiSakyy/Lsmsnksoslalql/raw/refs/heads/arena/1e52fcec-lsmsnksoslalql/handoff/rigged/anime-girl-rigged.glb)**

Предыдущая облегчённая модель на 18 МБ **заменена исходной детализацией**:
**1 159 795 вершин, 1 981 742 треугольника, текстуры 4096 × 4096**.

Основной GLB сохранён непосредственно в ветке `arena/1e52fcec-lsmsnksoslalql`,
[`handoff/rigged`](handoff/rigged/). Для получения файла сайт или эмулятор не нужен.

### Исправления привязки

Суставы подогнаны по сечениям **реальной исходной 3D-геометрии**: исправлена глубина
свободной руки и правильно учтена отведённая назад нога. Веса пересчитаны через
**libigl bounded biharmonic weights**, с плавным ограничением дальних влияний рук
и передних прядей. Полный меш получает веса по **ближайшему треугольнику с
барицентрической интерполяцией**, а не по трём случайным соседним вершинам.

**16-битные веса**, до четырёх влияний на вершину, **0 непривязанных вершин**.
48 костей тела, волос и одежды; пять процедурных клипов:
`Idle`, `Walk_InPlace`, `Run_InPlace`, `Wave`, `Dance`.

### Проверено качество, а не только формат файла

Проверены **21 время каждого клипа на самом экспортированном полном GLB**.
В `Wave` худший 99,5-й процентиль растяжения физических рёбер — **1,567**;
у отвергнутой облегчённой версии был **9,657**. Для остальных клипов — **1,09–1,323**.
Это измерение на проверенных временах, не гарантия идеальной деформации в любой позе.

Офлайн-рендеры **самого исходного высокодетализированного меша**:
[исходная поза](handoff/rigged/quality/source-rest.png),
[после привязки в той же позе](handoff/rigged/quality/rigged-rest.png),
[движение руки](handoff/rigged/quality/wave-check.png).
Это не интерактивный просмотрщик и не картинка костей вместо модели.

Официальный валидатор Khronos: **0 ошибок, 2 предупреждения** — исходный меш
не содержит явных касательных нормал-карты; локальная трансформация skinned-node
не применяется движком. Исходные данные не переписываются для скрытия этих предупреждений.
Проверены bind-матрицы и сохранность позиций: максимальная ошибка в исходной позе —
**0,000000304 единицы модели**.

### Повторная сборка

Blender 4.2 LTS (`bpy`), libigl 2.6.3, NumPy и SciPy.
[Workflow](.github/workflows/rig-model.yml) работает только в текущей ветке;
[33 теста](tests/rigging/) проверяют ZIP, реальные сечения модели, BBW,
точность весов, перенос между поверхностями, сохранность исходных буферов и анимации.
Служебная поверхность на 160 000 треугольников используется только для расчётов,
**не выдаётся как результат**. По умолчанию Actions делает файлы и три офлайн-рендера
для проверки; расширенный `render_previews` необязателен.

Это модель-специфичный автоматический FK-риг, не ручной production-риг: без мимики,
отдельных костей пальцев и физической симуляции ткани. Экстремальные изгибы и контакт
с волосами могут требовать ручных корректирующих форм. Движения процедурные,
не motion capture Mixamo. Исходный ZIP, сервер и его конфигурация не изменены.
