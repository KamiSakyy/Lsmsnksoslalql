# 🎌 Аниме-бот AniLibria → Telegram (MTProto, файлы до 2 ГБ)

Полная документация — в [BOT_README.md](BOT_README.md). Кратко:

* **Поиск только инлайном**: `@ваш_бот наруто` — карточка тайтла, тап → сразу выбор серии и качества.
* **Скачивание HLS-сегментов параллельно и адаптивно** (безопасный старт 3 → быстрый разгон до 6 → 8),
  с heartbeat-прогрессом, чтобы сообщение не «залипало на 0%» при паузах CDN.
* **Канал-хранилище + Firebase RTDB**: серия скачивается один раз, уходит в канал
  `-1004445072922`, а её `message_id`/`file_id` пишутся в RTDB (`anime/media/...`).
  Повторный запрос любой серии любым пользователем — мгновенная **копия из канала**
  (без скачивания и без имени канала в сообщении).
* **Диск не забивается**: после успешной отправки mp4/превью/сегменты удаляются.
* Деплой: Dockerfile в корне ветки (`arena/9afa2ee0-lsmsnksoslalql`), Railway → Root = `/`,
  Volume на `/data`.
